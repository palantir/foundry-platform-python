# Position

A GeoJSON position array of either two elements (`[longitude, latitude]`) or three elements
(`[longitude, latitude, elevation]`). Longitude and latitude are represented in WGS84 decimal
degrees and elevation in meters.

## Type
```python
List[Coordinate]
```
