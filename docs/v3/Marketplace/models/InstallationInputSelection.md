# InstallationInputSelection

Which fulfilled installation inputs to return based on their source.

Values:
- **ALL**: Include inputs from every stored source.
- **MANUAL_ONLY**: Include manually fulfilled inputs only.

| **Value** |
| --------- |
| `"MANUAL_ONLY"` |
| `"ALL"` |
