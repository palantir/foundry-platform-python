# MarkingProminence

How commonly a CBAC marking is used. COMMON markings are frequently applied; UNCOMMON
markings are rarely needed, so marking pickers may show them in a secondary list.


| **Value** |
| --------- |
| `"COMMON"` |
| `"UNCOMMON"` |
