# ParameterAccessMode

READ_ONLY: Allows the variable to be read by the Chatbot Studio Agent, but the Chatbot Studio Agent cannot generate updates for it.
READ_WRITE: Allows the variable to be read and updated by the Chatbot Studio Agent.


| **Value** |
| --------- |
| `"READ_ONLY"` |
| `"READ_WRITE"` |
