# ParameterAccessMode

READ_ONLY: Allows the parameter to be read by the Agent, but the Agent cannot generate updates for it.
READ_WRITE: Allows the parameter to be read and updated by the Agent.


| **Value** |
| --------- |
| `"READ_ONLY"` |
| `"READ_WRITE"` |
